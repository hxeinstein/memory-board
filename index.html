우리 반 추억 칠판

사진으로 1년을 돌아보고, 친구들이 그린 그림과 한마디로 칠판을 채워요

📷 사진 보며 돌아보기→🖍️ 한 명씩 칠판 채우기→💡 불 끄고 인사

예시 학생 16명 · 3월~12월 사진 · 잔잔한 배경음악으로 2분 30초 동안 전체 흐름을 보여 줘요. 내 학생 목록은 바뀌지 않아요.

1학생에게 그림판 주소 보내기

학생은 휴대폰으로 그림판을 열어 이름 · 분필 그림 · 한마디를 쓰고, 완성 후 [카톡으로 선생님께 보내기]를 누르면 돼요. 반 단톡방이나 선생님께 보내게 안내해 주세요.

📮 구글 설문으로 바로 받기 (선택 · 처음 한 번만 5분)

설정하면 학생은 카톡 대신 [선생님께 보내기] 버튼 한 번으로 제출해요. 학생은 설문지를 따로 보지 않아요.

📄 설문지 사본 만들기구글 계정으로 로그인한 뒤 [사본 만들기]를 누르면 내 드라이브에 설문이 생겨요.
  1. 위 [설문지 사본 만들기]를 눌러 내 설문을 만들어요. 질문(칠판 코드, 장문형)은 이미 들어 있어요.
  2. [응답] 탭 → [Sheets에 연결]을 눌러 응답 시트를 만들어요. 사본에는 응답 시트가 따로 없어서 꼭 해야 해요.
  3. [설정] → 응답에서 '이메일 주소 수집'은 수집하지 않음, '응답 횟수 1회로 제한'은 끔인지 확인해요.
  4. 오른쪽 위 [게시](종이비행기 모양)를 눌러요. 학교 계정이면 응답자를 '링크가 있는 모든 사용자'로 두세요. 학교 사용자로 제한하면 학생 휴대폰에서 자동 보내기가 막혀요.
  5. 오른쪽 위 ⋮ → 양식 미리 작성 → 칸에 아무 글자(예: test) → 링크 받기 → 링크 복사를 하고, 아래에 붙여넣으면 우리 반 전용 그림판 주소가 만들어져요.

2학생 코드 붙여넣기

카톡으로 받았다면: PC 카톡 대화방 → ≡ 메뉴 → 대화 내용 → 대화 내보내기로 받은 .txt 파일을 아래 [카톡 대화 파일 불러오기]로 열거나, 메시지를 복사해서 붙여넣으세요.
설문으로 받았다면: 응답 시트를 통째로(Ctrl+A → Ctrl+C) 복사해서 붙여넣으세요.
글 속에서 코드만 알아서 찾아요. 나중에 받은 것도 계속 넣으면 더해지고, 같은 이름은 마지막 것으로 바뀌어요.
